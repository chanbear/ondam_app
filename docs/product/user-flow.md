# 사용자 Flow

> 기존 온담앱(https://ondam-web.pages.dev/, /guardian)을 실제로 조작하며 확인한 흐름. `current-app-analysis.md` / `feature-spec.md`와 함께 참고한다.

## 1. 어르신용 온담 - 최초 진입 ~ 홈

```
스플래시 ("온담 시작하기")
 ↓
로그인/회원가입 (전화번호 + 4자리 PIN)
 ↓
온보딩 1: 접근성 설정 (글자크기 / 음성속도 / 음성안내 / 언어) → "다음"
 ↓
온보딩 2: 내 정보 (이름 / 성별 / 나이 / 지역) → "다음" (또는 "건너뛰기")
 ↓
온보딩 3: 보호자 정보 (보호자 이름 / 전화번호) → "저장하고 기능 설명 보기"
 ↓
홈 진입 + 3단계 튜토리얼 오버레이 (문서 찍기 / 수상한 문자 확인 / 경로당 찾기)
 ↓
홈 화면 (일반 모드)
```

## 2. 어르신용 온담 - 홈에서의 주요 행동

```
홈
 ├─ [문서 촬영] 클릭 → AI 분석하기 화면 (사진 촬영하기 / 사진 불러오기)
 ├─ [문자 내용 요약] 클릭 → (웹) "안드로이드 전용" 안내 → 홈으로
 ├─ [주변 복지센터·경로당 찾기] 클릭 → 위치 자동조회 시도
 │      ├─ 성공 시: 주변 경로당/복지센터 리스트
 │      └─ 실패 시: "불러오지 못했어요" → 주소 직접 입력 → [찾기] → 리스트
 ├─ [오늘 해야 할 일 - 전체 보기] → 기록 탭의 일정으로 이동(추정)
 ├─ [도움] 플로팅 버튼 → 긴급 도움 모달 (보호자 / 119 / 112 / 118 / 사용법 다시보기)
 └─ [쉬운 모드] 토글 → 동일 홈을 대형 버튼 UI로 재렌더링 (⇄ 일반 모드로 즉시 복귀 가능)
```

## 3. 어르신용 온담 - 하단 네비게이션

```
[정보] → 알아두면 좋은 정보(맞춤 카드 3개) + 근처 경로당 리스트
         └─ 카드 클릭 → 상세 안내(설명 + 신청방법 + 외부링크 + 전화)

[홈]   → 위 2번 흐름

[기록] → 분석 기록(Empty) / 일정(Empty)

[더보기] → 프로필 요약 카드
            ├─ 내 정보 (프로필 수정)
            ├─ 분석 기록
            ├─ 통계 → 고지서 통계(Empty)
            ├─ 알아두면 좋은 정보
            ├─ 사용 방법 안내 → 7단계 전체 튜토리얼 재실행
            ├─ 설정
            │    ├─ 글자크기 / 음성속도 / 음성안내
            │    ├─ 계정(마스킹된 전화번호) / 로그아웃 / 회원 탈퇴
            │    ├─ 보호자 정보(이름/전화번호 수정) + "위험 문자 발견 시 보호자에게 알릴지" 토글
            │    └─ 언어 설정
            └─ 고객 지원
                 ├─ 사용 방법 안내
                 ├─ 화면 안내(첫 실행 안내) 다시 보기
                 ├─ 고객센터 연결
                 └─ 개인정보는 어떻게 보관되나요? (정적 안내)
```

## 4. 보호자용 온담 - 연결 전 ~ 연결 후

```
/guardian 랜딩 ("부모님 곁에 한 걸음 더 가까이")
 ├─ [연결 전 화면 미리보기] → Mock 데이터로 채워진 홈 (실제 연결 없이 UI 체험)
 └─ [어르신 전화번호 입력] → [부모님과 연결하기]
        ↓ (같은 브라우저에 로그인된 어르신 계정을 찾아 매칭 — 프로토타입 한정 동작)
     연결 성공 → 보호자 홈
```

## 5. 보호자용 온담 - 연결 후 주요 행동

```
보호자 홈 (연결됨)
 ├─ 상단: 어르신 프로필 카드(이름/나이/지역) + 전화 버튼
 ├─ "오늘의 안심 상태" 배너 (위험 있음 / 없음)
 ├─ "최근 활동" (전체보기 → 분석 기록과 동일 목록으로 추정)
 └─ "다가오는 일정"

[받은 연락] 탭
 → 어르신이 "보호자에게 알리기" / "자녀에게 보내기"를 누른 항목 리스트 (읽음/안읽음)
 → 항목 클릭 → 상세 모달 (원문 / 위험 감지 배지 / 요약 / 주의 이유 / 확인할 일 체크리스트)

[기록] 탭
 → 어르신이 확인한 문서/문자 이력, 필터(전체/위험/문서/문자)

[통계] 탭
 → 이번 달 분석 수 / 위험 문자 수 / 완료·잔여 일정 / 최근 4주 활동 그래프

[더보기] 탭
 ├─ 최신 정보 불러오기
 ├─ 어르신용 앱 열기 (→ 어르신 홈으로 페이지 전환, 별도 인증 전환 없음)
 ├─ 다른 휴대폰 연결 안내 (연결 절차 설명 모달)
 ├─ 위험 알림 토글 (새 위험 문자 발생 시 알림)
 └─ 연결 해제 (이 기기의 보호자 연결 종료)
```

## 6. 두 앱의 실제 연동 흐름 (관찰 기반)

```
[어르신 앱] 온보딩에서 보호자 이름/전화번호 등록
        ↓
[보호자 앱] 랜딩에서 동일한 어르신 전화번호 입력 후 "부모님과 연결하기"
        ↓ (프로토타입: 같은 브라우저의 로컬 데이터에서 매칭 / 실제 서비스: 서버 조회 + 인증 필요 - 미구현)
[보호자 앱] 연결 성공 → 어르신 프로필(이름/나이/지역)과 등록된 보호자 이름이 그대로 반영되어 표시됨
        ↓
[어르신 앱] 설정에서 "위험 문자 발견 시 보호자에게 알릴지" 켜고, 실제 위험 문자 분석 후 "보호자에게 알리기" 클릭 (※ 이번 세션에서는 문자 기능 자체가 웹에서 비활성이라 이 마지막 단계는 재현하지 못함 — 확인 필요)
        ↓
[보호자 앱] "받은 연락"에 새 항목 도착 (추정 — 직접 재현은 못했으나 화면 문구와 구조로 유추)
```
